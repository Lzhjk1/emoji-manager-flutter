# 更新日志 (CHANGELOG)

本项目从 0.0.3 起开始整理版本记录；更早的版本（0.0.1 ~ 0.0.2）没有留发布记录，
其内容已并入 0.0.3 条目。各版本内容依据 git 提交历史（`git log`）整理。

## 0.0.3-rc8 (2026-09-03)

- 长按/按下预览图预热：指针按下瞬间即按「窗口尺寸 × dpr」后台 `precacheImage` 解码，遮罩打开时直接命中缓存，消除数百毫秒的解码停顿
- 网格小卡片关闭 18px 模糊阴影（`ImageCard` 新增 `showShadow` 参数）：立即模式下同屏大量卡片的模糊阴影每帧重算导致光栅线程饱和，是滚动卡顿主因；分类卡片等大卡片保留阴影
- 新增已知问题清单（`docs/known-issues.md`）

## 0.0.3-rc7 (2026-09-03)

- 悬停底栏改用 `ValueNotifier<EmojiItem?>` + `ValueListenableBuilder` 局部刷新，替代整页 `setState`，减少滚动时的频繁重建
- 网格列表增加 `scrollCacheExtent: ScrollCacheExtent.pixels(600)` 预载缓冲，减少滑入视口时的构建和解码延迟

## 0.0.3-rc6 (2026-09-03)

- 缩略图生成改为引擎按目标尺寸（≤256px）缩放解码：原 image 包路径不支持缩放解码，须先全量解码原图（宽×高×4）再做正方形裁剪复制，单张大图瞬态可达上百 MB；且 compute 后台 isolate 释放的堆页回到 isolate group 页池不归还操作系统，批量生成时工作集被推高后停在峰值。现 JPEG/WebP 走解码器原生缩放（不物化全尺寸位图），裁剪/编码在 256px 小图上进行，单张瞬态降至 1MB 以内

## 0.0.3-rc5 (2026-09-03)

- 网格 GIF 按网格尺寸限流解码：GIF 不落盘缩略图、直接以源文件播放动图，此前每帧都按原图尺寸解码（含帧合成缓冲），可见 GIF 较多时内存累积明显；现与静态缩略图统一为 `min((gridThumbnailSize + 16) × dpr, 256)` 限流，`fit` 策略保证非正方形 GIF 不变形
- 「刷新缩略图」由逐出单个 FileImage 缓存键改为清空图片缓存（网格/预览均经 ResizeImage 包裹解码，缓存键含各自目标尺寸无法逐一枚举）
- 新增 `build-and-pack.ps1` 一键构建打包脚本（flutter build windows + Inno Setup）

## 0.0.3-rc4 (2026-09-03)

- 长按缩放预览（覆盖层）由全尺寸原图解码改为按覆盖层实际约束 × dpr 降采样解码，修复翻阅/预览大图后工作集内存暴涨
- 修复预览弹窗图片非等比压扁变形：`ResizeImage` 同时指定宽高时默认 `exact` 策略会强行拉伸，改用 `fit` 策略等比缩放

## 0.0.3-rc3 (2026-09-03)

- 自动粘贴统一改为**原文件形式**复制粘贴（CF_HDROP）：保留 GIF 动画与 JPEG/WebP 压缩，避免 QQ 等软件把位图重新编码成大体积 PNG；位图（CF_DIB）通道保留备用
- 安装包版本号同步提升

## 0.0.3-rc2 (2026-09-03)

- 设置界面显示应用版本号（新增 `lib/app_version.dart` 作为版本号单一来源）
- 安装脚本：安装前 `taskkill` 旧进程，避免静默卸载失败

## 0.0.3-rc1 (2026-09-02)

- 检测前置应用自动粘贴：唤起时判断当前前台应用是否在指定列表（可在设置中配置），命中则同时复制到剪贴板并粘贴到目标聊天窗口；新增可配置的全局唤起热键
- 混合索引重构：一图多分类（文件仍按主分类目录存放，中央索引 `library.json` 记录附加分类 link）、导入自动去重（size 预筛 + SHA-256 精验）、链接自愈（文件改名/移动后按 size + 哈希找回，结果浮动卡片提示）、应用日志（`<根目录>/logs/` 每次启动一份，保留 30 份）
- 网格拖拽重排序（顺序持久化）、长按放大预览（200ms 触发，悬停切换）
- 右键菜单新增快速「设置备注」入口；悬停信息改为悬浮底栏显示
- 修复 `image` 包无法解码含 RST 重启标记 JPEG 的问题，改用引擎原生解码兜底
- 隐藏窗口前先最小化以暂停引擎渲染，降低常驻内存
- 为 Dart 与 C++ 代码补充分层架构中文注释，MSVC 启用 `/utf-8`
- 添加 MIT License

## 0.0.3 (2026-07-08 ~ 2026-09-01)

- 完成表情包管理器主功能：分类管理、网格浏览、Windows 托盘常驻、缩略图缓存
- 内存占用优化：全局 ImageCache 上限、网格/分类/预览均按实际显示尺寸（× devicePixelRatio）解码、缩略图生成移入后台 isolate
- GIF 表情动图播放策略调整（缩略图显示动图而非静态帧）、默认字体统一、图片适配方式改为 Contain
- 优化主界面布局与桌面交互；将 tooltip 从 UIA 树排除，修复触发过多提示消息的问题
- 支持唤起时向 QQ 等应用自动粘贴图片，并新增全局快捷键
- 右键菜单：刷新单张表情缩略图、在资源管理器中显示图片文件
- 支持拖入图片/文件夹添加到当前分类
- 添加 Inno Setup 安装脚本，产出 Windows 安装包
